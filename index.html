Google Gemini API 설정

ART INSIGHT는 가짜 데모 결과가 아닌 실제 Google Gemini 1.5 비전 모델을 호출하여 이미지를 심층 분석합니다.

💡 Gemini API 키 무료 발급 (1분 소요):
1. Google AI Studio (클릭하여 이동)에 접속합니다.
2. 구글 계정으로 로그인 후 "Create API key"를 누릅니다.
3. 발급받은 키(AIzaSy...)를 아래에 붙여넣고 저장하세요.

* 입력된 API 키는 브라우저 내부(LocalStorage)에만 안전하게 보관됩니다.

* 최신 고성능 Flash 모델(gemini-3.8-flash)이 우선 연결되며, [실시간 조회]를 누르면 사용자 계정에서 활성화된 모델을 즉시 확인합니다.
